# Fluxo SDD

Este projeto base organiza desenvolvimento por artefatos pequenos e reaproveitáveis.

## Ordem recomendada

1. Use `01-brainstorm` para gerar `.agents/spec/<spec>.md`.
2. Use `02-plan` para gerar `.agents/plan/<plan>.md`.
3. Use `03-implement` para executar as tasks.
4. Use `04-review` para revisar a entrega.
5. Use `05-debug` quando houver falha ou regressão.
6. Use `06-subagents` quando o plano puder ser dividido com segurança.

## Convenções

- Descrições, decisões e explicações ficam em português.
- Códigos, comandos, tags, paths, identifiers e nomes técnicos podem ficar em inglês.

## Inspiração

As skills foram adaptadas a partir de ideias do repositório Superpowers, especialmente os fluxos de brainstorming, planning, executing plans, TDD, debugging, code review e subagent-driven development.
