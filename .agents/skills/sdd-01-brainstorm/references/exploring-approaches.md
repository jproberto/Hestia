# Explorando Abordagens

Antes de fechar o design, apresente 2-3 abordagens diferentes.

Para cada abordagem, inclua:

- Ideia central.
- Como funcionaria.
- Pontos fortes.
- Riscos.
- Custo ou complexidade.
- Quando escolher.

Conduza a conversa com uma recomendação clara. Se uma abordagem for melhor, apresente-a primeiro e explique por que. Se ainda houver incerteza, diga o que falta para decidir.

Evite escolher a primeira solução sem comparar alternativas. A comparação é parte do design.
